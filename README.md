# StellarHeal – Intelligent Mental Health Support Assistant

An intelligent mental health support chatbot developed using **Streamlit and the DeepSeek large language model**, providing personalized, multi-role emotional companionship and psychological support. The system supports conversation management, AI role customization, local data storage, and other features.

## Project Overview

StellarHeal (Xingyu) is a lightweight intelligent mental health support application designed to provide users with warm, professional-style emotional companionship and psychological support. The system supports customizable AI personalities, automatic conversation saving and management, contextual memory, streaming responses, and other core features. All conversation data is stored locally to enhance user privacy and data security.

## Project Development and Update Process

The development and iteration of this project were divided into four main stages, progressively improving its functionality and user experience:

1. **Basic Interface Development and Interaction Implementation**: Established the basic interface configuration, including page titles, icons, and layouts. Implemented essential chat interactions, such as user input and real-time AI streaming responses. Integrated the DeepSeek large language model API to enable fundamental conversational capabilities.

2. **Sidebar Functionality Enhancement**: Developed a sidebar module featuring predefined AI role selection, customizable identities and personalities, and adjustable conversation parameters, such as context length and creativity level, to enhance personalization and user control.

3. **Conversation Management and History Implementation**: Implemented comprehensive conversation management features, including creating, loading, and deleting conversations, as well as automatically generating and manually editing conversation titles. Introduced local JSON-based storage to enable persistent conversation history and its visualization within the interface.

4. **Overall System Optimization and Enhancement**: Added advanced features such as batch conversation management, conversation export, conversation statistics, and automatic saving. Improved interaction logic and error handling, strengthened privacy protection mechanisms, and enhanced overall system stability, usability, and security.
